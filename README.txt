PORTAL BROWSER — UI UPGRADE v6
================================

This package upgrades the Portal Browser interface while retaining the existing
purple visual identity and Scramjet/BareMux/Wisp backend configuration.

UI additions:
- Refined purple glass-style workspace with animated accents and transitions.
- Removes preset/autogenerated quick recommendation tiles.
- Search/address bar with configurable DuckDuckGo, Brave, Google, or Bing search.
- User-managed bookmarks (the start page only displays links the user saves).
- Local recent-pages panel with a clear-history control.
- Improved multi-tab strip, close buttons, tab count, and keyboard shortcuts.
- Settings drawer for appearance, motion, search engine, local history, transport,
  endpoint information, diagnostics, and manual Scramjet storage repair.
- Responsive layout for small screens.

Existing proxy/server components are retained. Transport settings are compatibility
choices only; they do not override website rules, school/work network policies,
regional limits, age restrictions, sign-in requirements, or other access controls.

RUN LOCALLY
-----------
Requires Node.js 20 or newer.

1. Extract this folder.
2. Open a terminal in this folder (the folder containing package.json).
3. Run: npm install
4. Run: npm start
5. Visit: http://localhost:8080

RENDER
------
Runtime: Node
Build command: npm install
Start command: npm start
Root directory: repository root (package.json must be here)
No API keys or environment variables are required by this configuration.

After deployment:
- /healthz reports the deployed build.
- /__portal/diagnostics checks static Scramjet/BareMux/transport assets.

IMPORTANT TESTING NOTE
----------------------
Run `npm test` to perform local static checks. These checks do not prove that every
third-party website will load through the proxy. Some sites block proxy traffic or
require their own authentication and browser capabilities.
